## 复现命令

在仓库根目录执行：

```bash
make install
make check
make test
make api
make package
make smoke-package
```

发布验证使用本机操作系统，未宣称已完成无 Python/Node 的全新机器或其他操作系统验证。构建包尚无双源子进程、数据库核算、风控或日报功能；最终发布仍需验证这些业务及其资源完整性。
