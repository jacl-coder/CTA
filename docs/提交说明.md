# 机试项目提交说明

本项目依据《机试题目-多品种期货交易风控系统.md》实现，包含行情接入、持仓管理、盘中风控、盘后清算与日报四个核心模块，以及历史规则回放、实时仪表盘、配置化和多账户批量对比四个附加项。

## 交付内容

- 完整项目包：`cta-risk-delivery-linux-x86_64.tar.gz`，包含 Python/React 源码、注释、锁定依赖、配置、测试、技术与使用文档、代码展示图和可执行目录。
- 校验文件：`cta-risk-delivery-linux-x86_64.tar.gz.sha256`。
- 本次验收记录：随提交提供 `verification/`，含解压包逐项验收结果及日志。`result.json` 中的归档摘要应与项目包一致。

项目包中不包含开发机历史数据库、个人环境配置、虚拟环境或 node_modules。包内 `MANIFEST.json` 记录源代码提交号、文件摘要和构建环境。

## 快速运行

已验证环境：Ubuntu 24.04.4、Linux x86_64、glibc 2.39。可执行程序无需另行安装 Python、Node.js、uv 或 npm；Windows、macOS 和其他 Linux 环境需另行构建或验证。

在项目压缩包所在目录执行：

```bash
sha256sum -c cta-risk-delivery-linux-x86_64.tar.gz.sha256
tar -xzf cta-risk-delivery-linux-x86_64.tar.gz
cd cta-risk-delivery
./dist/cta-risk/cta-risk serve
```

浏览器访问 `http://127.0.0.1:8004`。按 `Ctrl+C` 退出。请保持整个可执行目录完整；若已有同一程序运行，先关闭旧进程以释放端口。

首次启动进入正常持续行情，两个独立模拟行情源自动启动。模拟源用于稳定复现断线、补数及风险阈值场景，不连接真实交易账户。程序数据写入解压目录的 `var/`，后续重启恢复已有进度。

## 建议查看顺序

1. 账户总览：查看三个账户与三个品种，勾选账户对比资金和风险，展开查看生效规则。
2. 顶部选择“手工演示”：提交初始行情，A 开多 1 手螺纹钢，将价格改为 3400 触发 3000 元浮亏熔断，再恢复 3500 验证当日熔断保持。
3. 风险事件和日结与日报：查看风险记录，封账、清算并结转下一日。
4. 顶部选择“故障与清算”：约 96 秒自动展示双源中断、补数、追溯熔断和两日日结。
5. 左侧“历史回放”：载入两日样例，对照 3% 与 5% 阈值，逐步查看熔断、拒单和平昨结果。回放不修改当前运行。

详细演示、手算与设计边界见包内 `docs/现场演示与答辩.md` 和 `docs/历史回放与附加项验收.md`。回放为有限历史输入的规则验证，不包含策略寻优、大规模历史研究或真实交易接入。
